# BlackeyesTech Landing Page

The technical standard for developer workflows. A high-performance, modular landing page featuring an architectural grid design system, interactive CLI telemetry dashboard preview, and a real-time Antigravity dot-particle interactive brand monogram engine.

## Features

- **Architectural 12-Column Grid**: Crisp background grid lines adhering to technical layout standards.
- **Master Monogram Vector**: Mathematically aligned SVG geometries for the `be` monogram brand across navigation and dashboard cards.
- **Dark Dashboard Preview**: Telemetry rails, mini bar charts, and code monitors.
- **Interactive Particle Engine**: 1600-particle canvas animation with real-time cursor repulsion physics, organic breathing oscillations, and uniform Fisher-Yates shape sampling.
